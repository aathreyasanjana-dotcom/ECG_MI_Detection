# ECG MI Detection

## Overview
This project detects Myocardial Infarction (Heart Attack) from ECG signals using a CNN-BiLSTM model.

## Features
- ECG preprocessing
- Beat segmentation
- Deep learning classification

## Dataset
PTB-XL

## Technologies
- Python
- TensorFlow
- NumPy
- Pandas
